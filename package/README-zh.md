# YinHuGuard 首次运行说明

## 这是什么

一个**只读**的排查工具，用来把「银狐」木马常见的隐藏进程与启动痕迹列出来。

它做的事情，来自一份流传较广的批处理脚本（原作者 B 站 @SYSTEM-RAMOS-ZDY）的三段扫描：

1. **隐藏进程** —— 找出可执行文件带「隐藏」或「系统」属性的进程
2. **隐藏启动项** —— 找出三个 Run 注册表键里指向隐藏文件的项
3. **可疑服务** —— 找出以命令行解释器启动、或程序不在系统目录下的服务

## 它不做什么

**这个工具不会修改你的系统。** 它不删文件、不改注册表、不动服务、不结束进程。
它只是读取并汇报。

原作者那份「解禁杀毒软件」脚本会做破坏性操作（删 hosts、删 WDAC 策略、写 IFEO 劫持、
禁用全部计划任务），**本工具不包含那些功能**。那些操作里有几处会伤到系统本身，
例如它会把 Windows 的卷影复制服务当成银狐驱动删掉。

## 怎么运行

1. 把整个压缩包解压到一个文件夹（**不要**在压缩包里直接双击）
2. 双击 `YinHuGuard.exe`
3. 点「开始扫描」

也可以命令行用：

```
YinHuGuard.exe --scan                     扫描并打印摘要
YinHuGuard.exe --json D:\report.json      扫描并把 JSON 报告写到指定位置
```

退出码：`0` 没有命中，`10` 有命中，`1` 参数错误，`2` 引擎错误，`3` 找不到配置文件。

## 首次运行被 Windows 拦住了

本工具**没有做代码签名**。个人开发者的代码签名证书需要每年约 200 美元，
一期没有购买，所以 Windows SmartScreen 会提示来源不明。这是预期行为。

处理方式：

1. 看到蓝色的「Windows 已保护你的电脑」窗口
2. 点**「更多信息」**
3. 点**「仍要运行」**

如果这个窗口让你不舒服，那是合理的——一个查杀木马的工具本身就值得怀疑。
你可以先只运行命令行模式（`--scan`），它会生成一份报告，而不是直接操作界面。

## 怎么读结果 —— 这一节最重要

### 「没有命中」不等于「机器干净」

这是使用这个工具最容易犯的错，也是它界面上反复强调这一点的原因。

普通权限下，**Session 0 的进程路径一条都读不到**（Windows 的权限设计如此）。
Session 0 是所有系统服务和后台进程所在的地方，也正是银狐这类木马最常藏身的地方。
所以不点提权的话，「扫描完成，没有命中」的真实含义是**「这一部分没有被检查过」**。

界面上的「本次扫描的覆盖范围」这一块就是为此存在的。请特别注意这几个数字：

- **管理员权限：否** —— 说明没提权
- **Session 0 可见进程：0** —— 说明系统进程一个都没看

出现这个组合时，界面会显示红色警告。**请务必以管理员身份重新扫描一次**，
再根据结果下结论。

### 报告里的标记

- `未覆盖` —— 这一项没被检查（通常是权限不够），**不是**「检查过没问题」
- `需要提权` —— 同上，且明确是因为权限
- `已按白名单折叠` —— 命中了白名单，收在下面但不隐藏，你可以回头看自己白掉了什么
- `隐藏属性` / `系统属性` —— 命中原因（文件属性）

### 报告可以发给人看

JSON 与 CSV 报告会自动把**你的用户名和机器名**替换成 `<USER>` 与 `<MACHINE>`，
**文件路径保持原样**。路径保留是有意的——帮你远程看报告的人需要知道文件到底在哪，
否则他无法判断该不该动手。

## 它可能报错（误报）

这个工具用的是「隐藏属性」这类启发式判据，**必然存在误报**。几种常见情况：

- 有些正常软件会把自己的文件设成隐藏
- 某些厂商的驱动、安全软件的服务路径本来就不在 `System32` 下
- 你自己隐藏过的文件

所以：**它列出来的东西需要人确认，不能直接照着删。**

如果要减少噪音，可以编辑程序旁边的 `rules.json`，在 `process_allowlist` 里加上
你觉得正常的东西。这个文件是纯数据，改坏了程序会拒绝启动并告诉你哪个键不对。

## 它读什么、不读什么

程序**不联网**，没有任何上传、没有崩溃上报、没有自动更新。
`rules.json` 就在程序旁边，你可以自己看里面判定用的是什么。

## 一个诚实的说明

本工具**只覆盖**银狐已知落点里的一小部分（隐藏进程、三个 Run 键、服务路径）。
它**不查**驱动、计划任务、WMI 事件订阅、注册表载荷、文件落点这些东西。

也就是说：**它说没问题，不代表真的没问题。** 它只是一个辅助手段。

如果怀疑机器确实中招了，正确处理顺序是：

1. 用这个工具看有没有明显痕迹
2. 装一个正规杀毒软件（火绒、360 均可）做全盘扫描
3. 杀毒软件也打不开的话，说明机器被劫持得比较深，考虑重装系统
